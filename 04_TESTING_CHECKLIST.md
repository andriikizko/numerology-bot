## 1. РЕГІОНАЛЬНЕ ТЕСТУВАННЯ

### 1.1 Реєстрація Користувача

- [ ] **/start** команда запускається без помилок
- [ ] Бот просить дату народження
- [ ] Формат помилки: вводимо "123" → "❌ Неправильний формат"
- [ ] Формат помилки: вводимо "32.13.2000" → "❌ Невірна дата"
- [ ] Формат OK: вводимо "15.03.1990" → Зберігається
- [ ] Дата в майбутньому: "15.03.2099" → "❌ Дата не може бути в майбутньому"
- [ ] Число долі розраховується правильно (15+03+1990 = 2008 = 10 = 1)
- [ ] Нумерологічне ім'я генерується (Число 1 → "Лідер")
- [ ] Користувач зберігається в Firestore правильно
- [ ] Trial гороскопу активується на 7 днів
- [ ] Головне меню показується після реєстрації
- [ ] Повторний /start показує меню (не заново реєстрація)

**Тестові дати:**
```
15.03.1990 → Число 1 (Лідер)
01.01.2000 → Число 2 (Дипломат)
25.12.1989 → Число 9 (Учитель)
11.11.1991 → Число 22 (Архітектор)
```

## 4. SECURITY ТЕСТУВАННЯ

### 4.1 Authentication & Authorization

- [ ] Користувач може читати тільки свої дані
- [ ] Користувач не може редагувати чужі дані
- [ ] Адмін може читати/писати всі дані
- [ ] Telegram ID верифікується

**Firestore правила:**
```
match /users/{userId} {
  allow read, write: if request.auth.uid == userId;
}
match /admin {
  allow read, write: if isAdmin(request.auth.uid);
}
```

### 4.2 LiqPay Webhook

- [ ] Підпис верифікується (SHA1)
- [ ] Невірна підпис → помилка
- [ ] Replay attack неможливий (timestamp, order_id)
- [ ] Данні не логуються (карти, тощо)

### 4.3 Telegram

- [ ] Bot token не логується
- [ ] Користувацькі дані зберігаються приватно
- [ ] Сообщення від користувачів логуються без чутливих даних

## 5.負ТЕСТУВАННЯ (Edge Cases)

### 5.1 Дати

- [ ] Дата на межі років (31.12.1999)
- [ ] Дата на межі місяців (31.01, 30.02 - помилка?)
- [ ] Дата 01.01.2000 (Y2K)
- [ ] Стара дата (01.01.1900) - помилка?
- [ ] Рівно сьогодні - помилка?

### 5.2 Числа

- [ ] Число 11 (майстер-число)
- [ ] Число 22 (майстер-число)
- [ ] Число 33 (майстер-число)
- [ ] Число 0 - помилка?
- [ ] Число > 9 - скоротити?

### 5.3 Платежи

- [ ] Платіж 0.01 грн (мінімум)
- [ ] Платіж 10000 грн (максимум)
- [ ] Платіж 249.49 грн - дробові?
- [ ] Повторний платіж одразу - дублювання?
- [ ] Перервана мережа під час платежу

### 5.4 Concurrency

- [ ] 2 платежи від одного користувача одночасно
- [ ] 2 гороскопи від одного користувача одночасно
- [ ] Daily function при 10k користувачів одночасно
